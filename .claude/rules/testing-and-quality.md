# 验证门与质量底线

## 1. 验证门

每个变更只有同时满足以下条件才算完成：

1. `docs/PRD.md` 或对应功能 spec 的验收标准满足。
2. §2 中受影响高风险区的测试通过。
3. 受影响的 Core、jrps、jrpc、Web 测试、静态检查和构建通过。
4. 需要官方 frpc、真实网络/NAT、浏览器、二进制或跨平台实机验收时，用户已确认结果。
5. 文档和 CHANGELOG 已同步，`git diff` 已审查。

完成必须有命令、关键输出、红转绿用例或实机结果作为证据。报告被测试或用户验收推翻时，回到原任务继续修复。禁止注释、跳过或删除失败测试。

修改功能代码前先运行相关测试确认基线；新增或修改业务逻辑必须同步测试。

## 2. 必测高风险区

### 2.1 module 与依赖边界

- Core 依赖图穷举禁止 frp、Gin、GORM、SQLite、apps module、Web 和通知依赖。
- jrps/jrpc 互相导入、管理 DTO 泄漏、packages 反向依赖必须被门禁阻止。

### 2.2 wire 与加密状态机

- wire v1/v2 正常帧、边界长度、截断、未知类型、未知字段、非零 flags、超限载荷。
- v2 魔数、hello、编码/加密协商、显式 v2 失败和禁止静默降级。
- 登录、token、时间窗口、重放、心跳超时、重复会话和非法状态迁移。
- 模糊测试不得导致 panic、无界分配、死锁或资源泄漏。

### 2.3 传输与工作连接

- TCP、KCP、QUIC、WS、WSS 的连接、超时、取消、半关闭、重连和 TLS 错误。
- 工作连接请求、池上限、运行 ID 归属、重复绑定、未知代理和清理。
- 所有网络 IO 位于锁外；竞态检测覆盖控制会话和代理生命周期。

### 2.4 代理、访客与 NAT

- TCP/UDP/HTTP/HTTPS/STCP/XTCP 的正常、冲突、拒绝和大流量边界。
- STCP 鉴权、允许列表、重放与信息泄露。
- XTCP 候选交换、超时、部分成功、失败回收和真实 NAT 环境。
- 代理×传输矩阵与固定基线官方 frpc 黑盒互操作。

### 2.5 无中断热更

- prepare、health-check、publish、drain 每一步成功与失败。
- 发布前失败保留旧 active/last-good，新资源完整释放。
- publish 原子性、新旧连接版本归属、长连接不中断、排空超时和并发更新冲突。
- 三项引导参数明确要求重启，其他配置不得通过重启测试冒充热更。

### 2.6 SQLite revision 与 outbox

- desired、active、last-good 不混淆；revision 冲突、幂等、崩溃恢复和事务原子性。
- SQLite WAL、备份/恢复、锁竞争、磁盘满和 Windows 文件占用语义。
- outbox 仅在事务提交后发送，覆盖重试、重复、超时、死信和进程重启。

### 2.7 HTTP 采集旁路

- 默认关闭且关闭时数据面不访问 SQLite。
- 只采集明文 HTTP；HTTPS 透传不生成正文。
- 流式压缩、分段切换、正文大小、并发、超时、磁盘满、崩溃恢复。
- 30 天与 5 GiB 任一先到的清理、索引/文件一致性、孤儿与缺失段。
- 正文查看/导出/删除审计，不泄露真实文件路径。

### 2.8 敏感数据与权限

- token、密码、Cookie、Authorization、SMTP/Webhook secret、正文不会进入日志、错误、指标或普通 API 响应。
- 单管理员 session、CSRF、越权、会话过期和速率限制。
- 每客户端 token 隔离、轮换、吊销和 jrpc 只能访问自身 desired state。
- 明文落盘事实与 SECURITY 文档一致，不出现虚假加密断言。

### 2.9 跨平台与文件语义

- Windows、Linux、macOS 的路径、权限错误、信号/关闭、SQLite/WAL、文件 rename/delete 和正文分段行为。
- 两个二进制构建并报告同一根 VERSION。

## 3. 质量底线

- 依赖单向，职责高内聚；禁止上帝类、循环依赖和有状态手写单例。
- 方法优先控制在 10–20 行，超过 30 行需拆分；嵌套不超过三层。
- 相似逻辑出现两次以上抽取复用，但不为单次使用创建抽象。
- 锁内不执行网络、数据库、文件或其他高开销 IO；资源必须可靠关闭。
- 大批量数据采用分页、流式或批处理，不一次性载入内存。
- 数据库和远程调用不得出现在循环中形成 N+1。
- 多处写操作在事务中原子完成，提交后才触发通知等副作用。
- 日志使用中文和正确等级，禁止临时打印；所有秘密与正文脱敏。
- 外部输入在边界校验长度、数量、枚举、地址、路径、帧和权限。
- 不硬编码凭证、端口、超时和魔法状态值，使用配置、常量或类型表达。
