# 注释与日志语言规范

## 1. 注释

- 仓库内所有人工编写的源代码和配置注释必须使用简体中文。
- 包括行注释、块注释、文档注释、JSDoc、待办说明、修复说明、注意事项和 YAML 注释。
- 英文标识符、协议字段、字符串字面量、许可证原文和隔离的第三方生成代码不视为人工注释。
- 修改代码时可翻译紧邻的英文注释，但禁止为统一语言大规模修改无关文件。

## 2. 日志与调试输出

- 所有正式日志和面向运维的诊断信息必须使用简体中文。
- 按 ERROR、WARN、INFO、DEBUG 使用等级，不混用。
- 生产代码禁止使用 `print`、`console.log`、`fmt.Println`、`System.out.println` 等替代日志。
- 日志包含必要请求 ID、客户端 ID、代理 ID 或 revision，但不得记录完整 token、密码、Cookie、Authorization、正文或其他隐私数据。

## 3. 例外

协议互操作要求的固定英文值、HTTP 头、错误机器码和第三方 API 字段保持原约定；其周边解释与日志仍使用中文。
